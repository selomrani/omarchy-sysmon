# Omarchy Sysmon 📊

A sleek, modern system monitor overlay plugin for the Omarchy shell.

## Features
- **Theme Adaptive:** Uses standard system palettes to automatically match your current Omarchy light or dark theme.
- **Glassmorphism UI:** Semi-transparent, beautifully rounded overlay.
- **Smooth Animations:** Hardware-accelerated easing animations for metric changes.

## Installation
1. Clone this repository into your Omarchy plugins directory.
2. Run `omarchy plugin validate` to ensure your system approves the manifest.
3. Enable the plugin via the Omarchy dashboard or shell.
